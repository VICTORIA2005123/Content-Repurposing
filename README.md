# Content Repurposing Chain

## Problem

Build an AI-powered content repurposing chain that transforms a
source article into:

Article → Summary → LinkedIn Post → X/Twitter Thread

while maintaining factual consistency at every stage.

## Prototype Goals

- Working Streamlit application
- Article input
- Fact extraction and Fact Ledger
- Prompt chaining
- Summary generation
- LinkedIn post generation
- X/Twitter thread generation
- Fact-drift detection
- Automatic regeneration when factual drift is detected
- Platform constraint validation
- Input and off-topic guardrails
- Refusal/invalid-output handling
- Prompt version comparison
- 10+ case evaluation
- Measured fact-consistency metric

## Technology

- Python
- Streamlit
- Generative AI API
- GitHub
